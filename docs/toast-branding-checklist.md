# Toast branding checklist for Panino's Pizza & Pasta

Use the real Toast admin account to make the ordering experience feel cohesive with the website.

- Upload the current Panino's logo and use the same tomato red, cream, charcoal, and basil green brand colors where Toast allows.
- Match category order to the website: Pizza, Pizza by the Slice, Specialty Pizzas, Strombolis, Calzones, Wings, Pasta, Salads, Hot Subs, Cold Subs, Desserts, Gelato, Drinks, Lunch Specials.
- Replace placeholder descriptions and prices with the live Toast menu.
- Add high-quality item photos for best sellers: cheese slice, pepperoni pie, Downtown Supreme, wings, chicken parm sub, spaghetti & meatballs, cannoli, gelato.
- Keep modifier groups simple: crust, size, toppings, sauce, add-ons, side choice, drink choice.
- Use consistent item naming and punctuation between Toast and the website.
- Toast typography is limited, so rely on clean photos, category organization, logo, colors, and concise descriptions.
- Confirm pickup/delivery hours match the website and Google Business Profile.
- Test the handoff from every website CTA to Toast on mobile and desktop.
- Add campaign-specific Toast links later for lunch specials, late-night promos, catering, and gift cards if supported.
